# Resume Library Search

Resume Library supports local filtering across:

- resume name
- company
- role
- status
- skills
- bullet text
- project and experience sections

Badges identify draft/ready, submitted, favorite, and archived states. Favorites and archives are stored separately from `resume_versions` so source versions remain immutable.

Recommendations can be generated for a selected target job. The UI shows component scores and reasons, lets the user dismiss recommendations, and supports creating a child draft from a recommended base resume.

Search documents also include resume summaries and individual resume bullets for Career Copilot and global hybrid retrieval.
